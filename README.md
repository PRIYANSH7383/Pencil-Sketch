# 🖌️ Krishna Pencil Sketch

A Python-based image processing project that converts a Krishna image into a pencil sketch using OpenCV, NumPy, and Pillow.

The project also includes a progressive drawing animation that reveals the sketch gradually, creating the effect of the image being drawn on paper.

## ✨ Features

- 🖼️ Load an input Krishna image
- 🎨 Convert the image into a pencil sketch
- ✏️ Create a progressive drawing animation
- 🌓 Grayscale and shading effects
- 💾 Save the final sketch as an image
- 🐍 Built completely with Python

## 🛠️ Technologies Used

- Python
- OpenCV
- NumPy
- Pillow
